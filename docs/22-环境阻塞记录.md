## 2. 判读要点（为何误判"docker 栈僵死"）

- **k8s 与 docker 双栈并存**：master/worker 均为 k3s（containerd k8s.io namespace）+ 独立 dockerd（moby）。
  项目 pod 全部走 k3s 栈；dockerd 只服务镜像构建/推送与 registry 容器。pod 侧全绿 ≠ dockerd 健康，反之亦然。
- **SSH 空闲掐流放大了卡死感知**：长无输出命令（docker build -q、docker info 大 catalog）在无 keepalive 会话上
  表现为"整条 SSH 挂死"。
- **dockerd Memory 10.5G（Tasks 60）**：大 catalog（166 镜像）+ 长运行 4 周，CLI 慢响应疑似 dockerd 内存/锁压力；
  未达到不可用程度（11-09 会话仍在同一 dockerd 上完成了 2.0/3.0 镜像构建推送）。
